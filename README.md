## 2026 Meta Cloud API Conversation Categories

Meta bills WhatsApp Business API usage based on 24-hour conversation windows initiated from user or business interactions:

1. **Marketing Conversations**: Customer outreach, product launches, promotions, and retargeting campaigns.
2. **Utility Conversations**: Order confirmations, shipping updates, payment reminders, and transaction receipts.
3. **Authentication Conversations**: One-time passcodes (OTP), multi-factor verification, and account recovery.
4. **Service Conversations**: Customer-initiated inquiries, inbound support questions, and live chat assistance.
